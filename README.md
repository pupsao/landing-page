## ✨ Project Highlights

This landing page is built to provide a seamless user experience, highlighting the aesthetics and technical superiority of the My Bike lineup.

* **Sleek User Interface:** A clean, modern design that adapts perfectly to desktop, tablet, and mobile screens.
* **Model Comparison:** Easily compare the specs, features, and pricing of our flagship models.
* **Interactive Details:** Dedicated sections exploring the bikes' smart features, including Auto Unlock, GPS tracking, and integrated lighting.
* **Direct Contact:** A streamlined section for users to book test rides or get in touch.
